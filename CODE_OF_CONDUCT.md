# Code of Conduct

## Our commitment

TrustCheck is a community project. We want participation to be respectful, harassment-free and
welcoming for everyone, regardless of background, identity, experience or language.

## Expected behaviour

- Be kind and patient; assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what is best for users’ safety and privacy.
- Respect that many contributors write in a second language.

## Unacceptable behaviour

- Harassment, insults, discriminatory language or personal attacks.
- Publishing others’ private information.
- Sharing live malware or phishing kits, or using the project to facilitate attacks.
- Sustained disruption of discussions.

## Enforcement

Maintainers may edit or remove contributions and temporarily or permanently ban participants who
violate this code. Report problems privately to the maintainers through GitHub
(Security → “Report a vulnerability” can be used for sensitive reports). Reports are handled
confidentially.

This code applies to all project spaces: issues, pull requests, discussions and any official
communication channels.
